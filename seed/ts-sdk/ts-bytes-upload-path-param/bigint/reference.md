## Service
<details><summary><code>client.service.<a href="/src/api/resources/service/client/Client.ts">uploadWithPathParam</a>(uploadable, tenantId, objectPath, revision, uploadedAt, region) -> void</code></summary>
<dl>
<dd>

#### 📝 Description

<dl>
<dd>

<dl>
<dd>

Bytes endpoint with required path parameters whose only example supplies no
path-parameter values (autogenerated examples are skipped for bytes bodies). The
generated example must still pass a value of the declared type for every path
parameter instead of omitting it or passing `undefined`. A parameter with a client
default is left out of the example, since the client supplies it.
</dd>
</dl>
</dd>
</dl>

#### 🔌 Usage

<dl>
<dd>

<dl>
<dd>

```typescript
await client.service.uploadWithPathParam(createReadStream("path/to/file"), "acme", "objectPath", BigInt("1000000"), "2024-01-15T09:30:00Z", "us-east");

```
</dd>
</dl>
</dd>
</dl>
